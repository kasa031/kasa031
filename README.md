### 🚀 Featured Projects

#### 📚 [MSc Cybersecurity Practise Syllabus](https://github.com/kasa031/msc_cyber-syllabus)
`JavaScript` • `PWA` • `Service Worker` • `Spaced Repetition`

Offline-friendly study app for MSc Cybersecurity year 1: terminal tutorial, Anki-style quizzes for ACIT4050, ACIT4280, and ACIT4100, class notes, and framework practice. Live on GitHub Pages.

🔗 **Live demo:** [kasa031.github.io/msc_cyber-syllabus](https://kasa031.github.io/msc_cyber-syllabus/)

#### 🗺️ [TagOslo](https://github.com/kasa031/TagOslo)
`Next.js` • `TypeScript` • `Supabase` • `Mapbox`

Interactive map for Oslo: find sun exposure, tag places with hashtags, and vote or give feedback in your district. Built with MET/Yr weather data.

#### 📡 [NetSec Network Security Assistant](https://github.com/kasa031/NetSec-Network-Security-Assistant)
`Python` • `Web Interface` • `Traffic Analysis`

Real-time network traffic analysis tool with a web interface for monitoring and inspecting network activity.

#### 🛡️ [ThreatInfo](https://github.com/kasa031/ThreatInfo)
`Java` • `OpenCSV` • `Data Analysis`

Cybersecurity threat analysis application for global and Norwegian threat data. Loads CSV/Excel, provides statistics, search, and filtering by country, type, year, and severity.

#### 💼 [JobCrawl](https://github.com/kasa031/JobCrawl)
`TypeScript` • `AI` • `Web Scraping`

Intelligent job application assistant with AI-powered cover letter generation and smart job scraping from Norwegian job sites.

#### 🗳️ [Pulse Oslo (experimental)](https://github.com/kasa031/pulse-experimental)
`React Native` • `TypeScript` • `Firebase`

Experimental branch of a civic voting app for testing new features and mobile UX.
